FULL LUỒNG SOFTPHONE

USER -> HOTLINE-FLUTTER: VAD -> VOICE -> STT(Faster whisper):TEXT -> RASA: TEXT_RESPONSE -> TTS

Chuẩn bị trước khi chạy server
	- cài venv và activate (rasa (py < 3.11) riêng src (py version có thể lấy phiên bản > 3.10) riêng do incompitable về một số lib)
	
	- src/
		- pip install sts/requirements.txt
		- khai baos model:
			tts = Vieneu()
		- các đối số của Vieneu: 
			- voice:
				"Minh Đức"
				"Phạm Tuyên"
				"Thái Sơn"
				"Xuân Vĩnh"
				"Thanh Bình"
				"Trúc Ly"
				"Ngọc Linh"
				"Đoan Trang"
				"Mai Anh"
				"Thục Đoan"
				"Minh Triết"
				"Thùy Dung"
				"Quang Sơn"
				"Ngọc Trân"

			- style:
				"tu nhien"
				"tin tuc"
				"doc_truyen"
	
	- rasa/
		- pip install rasa/requirements.txt
		- Nếu chưa có model: 
			Train full(core và nlu): chạy python utils/rasa_utils.py
		- Chưa có bộ phrases&placholder (hoặc chỉnh sửa)
			Trong utils/example -> thêm/sửa file txt -> quay lại /utils chạy file gen_txt_json.py
		- Train model ( chỉ nlu, core hoặc full)
			sửa ở main trong utils/rasa_utils -> chạy ( kể cả khi bật sv)
			
Chạy full luồng(CMD):
	client hotline: FLUTTER (sks talkie)
		- flutter clean
		- flutter pub get
		- flutter run -d window
		
	server src
		chạy file whisper_server.py 
		
	server rasa (folder rasa)
		rasa run actions -vv							/// bật actions 
		rasa run --enable-api --cors "*" -vv			/// bật server ( đoạn --log kia để lấy log runtime ra file trong /logs)
